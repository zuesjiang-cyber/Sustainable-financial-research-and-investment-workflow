## 本轮交付边界

复用现有服务端模型调用层，准备本地配置和独立连接检查命令，验证普通回复与工具调用协议。不改前端、数据库或投研业务，不调用自动财报搜索，不把模型连通等同于产品功能完成。

真实验收分两项：

1. 普通回复：项目代码向指定 Ling 模型发送小型合成文本，收到非空、可核对的真实回复。
2. 工具往返：收到模型工具调用，执行一个无外部副作用的合成测试工具，回传结果后收到模型回复。

连接检查应报告使用的模型、接口、耗时和可取得的 token 用量。缺密钥、接口失败或工具调用未完成时明确失败，不改用其他模型或样例回答。
