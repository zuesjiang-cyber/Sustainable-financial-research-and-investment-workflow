# FinTrust 成品 V1：研报观点核验与持续研究

设计日期：2026-09-03。状态：**完整目标设计，尚未实现验收**。

> 2026-09-04 当前 MVP 范围以 [完整 Walkthrough](17_MVP完整Walkthrough.md) 为准：财报由用户上传，不自动发现；PDF 原页查看暂缓；核心模型使用 Ling-3.0-flash-Fin。

这套文档描述最终交付的聚焦型产品，不是当前代码功能说明，也不是只做到下一轮的补丁计划。开发以本目录为准；旧的手工录入观点、单次测试工作台仅作为迁移来源。此次仅新增设计与执行文件，不修改业务代码。

## 产品的一句话

**上传一份研报，系统自动拆出值得跟踪的观点，用截至今天已公开的最新财报逐条核验，告诉你哪些得到支持、哪些出现差距、原因是什么；以后沿着同一组观点继续更新。**

用户需要操作的是研报、观点与判断，不是 Agent、工具、任务队列、事实表或 Memory 配置。

## 成品体验

1. 上传研报 PDF，系统识别公司、报告日期和观点。
2. 后台自动匹配最新正式财报，并读取需要的历史对比材料。
3. 一页看到「原观点 → 最新事实 → 判断与原因 → 下一步关注」，点数字或引文可回到 PDF 原页。
4. 用户修正少量观点或判断，点击「保存本次研究」。原始观点、系统分析、用户判断分别保留。
5. 新财报公布后，点击「检查最新财报」，或使用已开启的定期检查，得到相对于上次研究的变化。确认后形成下一版研究状态。

## 范围如何理解

这是一个完整的**研报观点核验产品 V1**，不是金融终端。最终 V1 覆盖沪深上市公司的中文公司研报、正式定期报告、持续研究和私人工作区。多公司行业研报在识别后选择一个目标公司继续；港美股及其他会计口径作为后续适配，不影响这条闭环的完整性。

所有纳入的需求均为 P0。开发可以分阶段交付，但最终必须把真实上传、自动获取、观点核验、证据定位、持久状态、第二轮更新和可部署运行连起来。
