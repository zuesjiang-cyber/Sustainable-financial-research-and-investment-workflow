# 05 财报获取与事实标准化

## 1. “最新财报”的精确定义

最新是：**截至本轮 asOf，目标公司已公开的正式定期报告中，报告期最新且修订有效的文件**。发布日期和财务所属期间分别保存。业绩预告、业绩快报、研报预测可以作补充，但不能冒充已经披露的正式报表。

资料包通常包含：最新季度/半年度/年度完整报告 + 最近完整年报的业务与会计政策信息 + 当前观点需要的同期比较数据。能在最新报告取得可靠比较数时，先复用，不无差别下载全部历史报告。年报摘要不替代年报全文。

## 2. 官方来源适配器

默认 CNINFO 公告检索作为沪深资料入口；SSE 官方公告目录作为上市场景的第二适配器。CNINFO 标明其为深交所信息披露网站，SSE 也提供上市公司公告目录。[CNINFO](https://www.cninfo.com.cn/new/index)、[SSE 公告](https://www.sse.com.cn/disclosure/listedinfo/announcement/)

这些网页和来源身份已核查，**当前项目尚无经真实下载验收的自动获取连接器**。公开页面的自动化可用性、分页、访问频率及返回格式是开发任务中的实测项，不能把页面存在当成接口已打通。

统一接口：

```text
resolveIssuer(securityCode, exchange) -> IssuerCandidate[]
listDisclosures(issuerId, publishedFrom, publishedTo, cursor) -> Page<Disclosure>
getDisclosure(id) -> {title, publishedAt, period, kind, revisionOf, pdfUrl}
download(disclosure, storage) -> {sha256, bytes, contentType, retrievalReceipt}
```

实现首先使用公开检索页：Playwright 在 Worker 复用浏览器实例，按证券代码、定期报告分类和日期筛选，读取公告记录、分页、点击详情取得真实下载地址。页面 selector 单独配置并以录制样本做契约测试；接口若有公开文档和凭据，再替换为同一 provider 的 HTTP 实现。设计不填未经核验的私有 API 地址或参数。

每域并发初值 1、请求间隔 2 秒、遵守服务器限流。遇到登录、验证码或访问限制停止该路径，记录具体缺失并提供用户补充；不把绕过访问限制作为产品能力。自动公开获取要在成品验收中以真实用例通过，手动补充不能替它交差。

## 3. 财报包选择算法

1. 查询 `[研报日期前一年, asOf]` 的目标主体公告；需要更早比较时按需向前延伸。
2. 将标题/公告分类映射为 ANNUAL/HALF_YEAR/Q1/Q3，过滤摘要、取消稿和无关主体。
3. 以明确报告期排序，而非文件名或抓取时间；没有明确期间的候选先读取封面核验。
4. 同期报告识别更正/修订关系，以截至 asOf 可获得的有效版本为准；保留旧文件供历史回放。
5. 根据观点计划确定必须的报告与可选背景资料；下载成功、哈希计算与原文件归档后才能进入资料包。
6. 存 manifest：document IDs/hashes、publication cutoff、latest covered period、检索来源/时间、缺失材料、选择理由。

“截至今天没有新财报”和“这次没查成功”是两个不同结果。后者保留旧覆盖日期并显示未完成检查。

## 4. 事实提取流水线

先解析完整财报并索引；事实提取聚焦本轮观点所需指标、对应主表、分部说明及原因段落。需要时工具补读其它页。这样避免把每一行都送给大模型。

数字事实：候选表格 → 科目/期间/单位/合并范围识别 → 标准指标映射 → 原始 cell/span 绑定 → Decimal 规范化 → 检查后入库。

文字事实：与观点相关的披露段落 → 抽取主体、事件、发生时间、管理层解释或前瞻性判断 → 原句绑定。管理层归因标记为 `MANAGEMENT_EXPLANATION`，并非经系统独立证明的因果。

## 5. 数字事实必要字段

| 维度 | 含义 |
|---|---|
| entity、segment | 公司与业务分部，缺失分部不能默认等于全公司 |
| metric、labelOriginal | 标准科目与原科目；保留映射版本 |
| periodStart、periodEnd、basis | YEAR、YTD、QUARTER、INSTANT；时点数据没有期间累加语义 |
| accountingStandard、scope | 默认中国企业会计准则 CAS；CONSOLIDATED/PARENT/SEGMENT |
| value、unit、currency | Decimal 字符串、金额/比例/数量、币种 |
| originalValue、originalUnit、scale | 原披露数值和单位，规范化过程可追溯 |
| nature | ACTUAL / FORECAST / GUIDANCE；研报预测不流入 actual 池 |
| publishedAt、restatementKey | 披露时点和重述口径 |
| evidenceIds | 数值单元格、科目行、期间列、单位说明和必要脚注 |

零值是 `"0"`，缺失是 null/缺失事实，不能互换。负数、括号负值、百分数、小数点与千分分隔按明确规则转换。比例规范化为 0–1：原文 30% → `"0.30"`，不是 `"30"`。

## 6. P0 指标注册表

默认原始指标：营业收入、营业成本、归母净利润、合并净利润、扣非归母净利润、经营活动现金流量净额、应收账款、存货、资产总额、负债总额；行业经营指标按研报需求提取为有明确单位的 custom metric。

派生指标：

- 毛利率 = (营业收入 − 营业成本) / 营业收入；收入为零时不可计算。
- 同比 = (本期 − 同期) / 同期；同期为负或零时改为差额和“扭亏/减亏”等分类，不无解释输出常规增长率。
- 毛利率变动 = 本期毛利率 − 对比毛利率，界面显示百分点，而非增长百分比。
- 单季收入 = 当期累计收入 − 上季度累计收入；单季成本、利润和现金流同理。
- 单季毛利率 = 用推导后的单季收入/成本重算；不能直接相减两个累计毛利率。

现金转化指标在注册表明确分母：例如经营现金流/合并净利润；如使用归母净利润则另设指标名并说明口径，不在同名指标中混用。

## 7. 对比前的兼容性检查

主体、分部、币种、单位、期间基础、合并范围和重述口径匹配后才计算。优先使用同份最新报告中的重述比较数。只能取得不同重述口径时，明确无法直接比较，不自动回退成看似精确的差额。

检查包含量纲一致、年度/累计/单季辨别、期末/期初辨别、表中金额缩放、可见小计与总计关系。报表原始列名与脚注是口径证据，不能由模型常识补齐。

## 8. 来源缓存与更新

文件以 workspace+SHA 去重，解析结果以 documentSHA+parserVersion+optionsHash 去重；授权范围内同文件可复用解析，不跨工作区泄露是否存在文件。公告有新修订时产生新 document，不替换原字节。

事实由文档版本、指标、维度、期间和提取版本唯一定位。冲突候选都保留，选用事实的理由写入 assessment/source pack。补充更清晰来源或升级提取器产生新提取版本，并让受影响的核验重跑。
