# 交互式研究 Demo（本地 MVP）

本轮只验证产品价值：投资观点持续跟踪、财报事实对照、人工修正、确认版本与历史回看。不接入新模型、上传流程、队列或数据库。

## 体验路径

1. 首页点击「体验观点跟踪 Demo」。
2. 查看 T0：六条初始观点均处于待跟踪状态。
3. 点击「载入示例财报核验」，生成预置的 T1 草稿。
4. 选择现金流等观点，检查原判断、示例事实、差距与解释。
5. 修改状态、研究员判断、下一轮问题。
6. 点击「确认本轮 · 写入 Memory」，生成不可直接编辑的已确认版本。
7. 通过时间线回看 T0 / T1；刷新页面后重新进入 Demo，记录仍在。
8. 点击「开启下一轮复核」，继承上轮人工判断；确认后生成 T2。
9. 导出 Markdown，或通过二次确认重置演示。

## 边界

- 示例事实和原因沿用仓库原有演示内容，没有实时模型调用或原件核验。
- T1 为预置财报核验；T2 及以后为同一份示例材料上的研究员复核，不宣称获得新一期财报。
- 数据位于浏览器 localStorage 的 `fintrust:interactive-demo:v1`，不调用项目写入 API，不写服务器 Research Memory。
- 未确认草稿仅在当前页面内存中；刷新会丢失草稿，已确认版本不受影响。
- 存储不可用时显示警告，可导出备份；损坏快照回退到初始演示。
- 清除浏览器数据会清除演示版本。真实 PDF 流程保持原状。

## 实现

- `src/components/research/DemoResearchView.tsx`：交互工作台。
- `src/components/research/demoWorkspace.css`：独立响应式样式。
- `src/lib/demoMemory.ts`：初始化、版本确认、跨轮继承与恢复。
- `src/lib/demoMemory.test.ts`：快照隔离、修正继承、恢复与损坏保护。

旧版设计文档中的「Demo 完全只读」约束由本文件更新：示例数据仍与真实项目隔离，但允许在浏览器沙盒中交互和保存演示版本。
