# FinTrust Thesis Update 架构决策与设计考量 (ADR)

## ADR-01: 确定性财务重算与 AI 语义比较严格隔离
- **背景**: 大语言模型在长篇财报处理中普遍存在两类致命问题：一是计算幻觉（例如混淆同比正负方向、浮点舍入漂移、多位数除法错误）；二是难以严格追溯页码与证据。
- **决策**:
  - 所有数值类指标（同比、毛利率、费用率、净现比）全部由 **Decimal 引擎** 确定性计算；
  - 大模型仅且仅用于受限的 **两期叙事语义差异提取 (Narrative Deltas)**；
  - 判定规则（保持/削弱/加强）基于 Decimal 精确值与前设阈值比对，杜绝大模型随机性。

## ADR-02: 草稿主张严格前置核验与主动拦截
- **背景**: 分析师或前期初稿常带有“笔误”或“乐观预测”（例如将现金流下降 15.11% 误写为增长 15.11%，将毛利率 50.94% 估测为 52.00%）。
- **决策**:
  - 引入 `ClaimAuditResult`（VERIFIED / MISMATCH）；
  - 任何被评为 MISMATCH 的草稿主张，系统强制拦截，禁止进入最终发布摘要；
  - 最终简报标注被拦截的纠错事实，确保研究合规性。

## ADR-03: 双端同构与证据链穿透 (Evidence-Traceable UI)
- **背景**: 买方投研极其看重“证据可验证性”，任何数字必须能定位到原始财报的页码与原文。
- **决策**:
  - 在核心数据结构中贯穿 `evidence_id`；
  - UI 抽屉随时展示报告名称、报告期、第几页、原文段落及高亮图证；
  - 支持一键导出可交付 Markdown 与可入库 JSON。
